# Phase 0 — 방향 리서치 & 권고 리포트

작성: 2026-06-07 · 대상: no-marathon.kr · prompt.md §06 응답

> 두 트랙("공익+AdSense" vs "공익표방→자산화/매각")을 트래픽·수익·매각가 근거로 비교하고
> 권고안과 트랙별로 달라지는 설계 항목을 정리한다.

---

## 1. 핵심 결론 (요약)

1. **단일 이슈·한국어·스파이크형 공익 사이트의 직접 광고/매각 경제성은 약하다.**
   AdSense 수익은 월 수만~수십만 원 수준에 그칠 가능성이 크고, 매각 시장(Empire Flippers 등)의
   최소 기준(월 순익 $500, 통상 $25k↑ 매물)에 도달하기 어렵다.
2. **그럼에도 "자산화 가능하게 설계"하는 비용은 거의 0에 가깝다.** SEO·분석·데이터 소유권·운영 문서화는
   공익 운영에도 그대로 도움이 되고, 나중에 트래픽이 예상 밖으로 붙으면 그때 수익/매각 옵션을 켜면 된다.
3. **따라서 권고는 사용자가 원한 dual-track 그대로:**
   **주(主) = "공익 + 비침습 AdSense" 운영**, **부(副) = "매각 가능 자산 수준으로 설계"(저비용 헤지)**.
   "처음부터 매각 목표"로 가는 것은 경제성이 받쳐주지 않으므로 비권장.
4. **진짜 잠재가치는 사이트 자체가 아니라** (a) 축적되는 *불편 그리에번스 데이터셋*,
   (b) 참여 오디언스, (c) "시민 불편 집계기" *재사용 템플릿*(다른 이슈로 재배포 가능, Ushahidi 모델)이다.
   매각 트랙을 진지하게 본다면 이 세 가지를 자산으로 봐야 한다.

## 2. 근거 데이터

### 2.1 AdSense RPM (1,000 노출당 수익)
- 일반/라이프스타일·뉴스·이슈성 한국어 콘텐츠: **RPM $1~$3** (약 1,300~3,900원). 뉴스/엔터·일반은 글로벌 기준 **$0.5~$3 CPM**으로 낮은 편.
- 고단가 니치(금융·보험·건강)는 $5~$15+지만 본 프로젝트 주제(교통/시민불편)는 **저단가 구간**.
- 영어권 트래픽은 한국 트래픽보다 RPM **2~5배 높음** → 본 사이트는 한국 트래픽이므로 낮은 쪽.
- 구글 수수료 약 32%, Q4가 Q1 대비 30~50% 높은 계절성.
- **본 사이트 현실 추정 RPM: $0.5~$2** (한국어 + 이슈/뉴스성 + 비침습 배치).

### 2.2 트래픽 특성 (스파이크형)
- 바이럴/이슈 트래픽은 **보통 1~2일짜리 스파이크**, 장기 지속은 "big break 오류". 미디어/소셜 픽업에 좌우.
- 본 사이트는 **마라톤 개최 주말에 집중**되는 전형적 event-driven 스파이크 구조(시즌: 봄·가을 집중).
- 즉 **상시 baseline 트래픽은 낮고**, 특정 시점에 한 곳으로 몰리는 구조 → 캐싱/스파이크 대응이 기술 핵심(Phase 8).

### 2.3 매각 시장 (콘텐츠 사이트)
- 콘텐츠 사이트 매각 배수: **월 순익의 30~45배**(2026 기준 블로그 35~45x), 디스플레이 광고 사이트 평균 **34.6x**, Empire Flippers TTM 평균 **31x**.
- Empire Flippers 상장 최소 기준 **월 순익 $500**, **$25k 미만 매물은 드묾**.
- 2025 콘텐츠 사이트 거래량 **37% 감소**(구글 알고리즘 영향) → 다변화 트래픽·전문성 선호.
- 배수를 **낮추는 요인**: 단일 트래픽 소스 의존, 단일 키워드/이슈 의존, 오너 노동 집약 →
  본 사이트는 이 세 가지에 **전부 해당**(AdSense 단일·단일 이슈·운영 의존) → **배수 하단** 적용 불가피.
- 배수를 **높이는 요인**: 트래픽 다변화, GA4/Search Console 문서화, SOP 문서화, 낮은 오너 개입 → **설계로 확보 가능(저비용 헤지의 근거)**.

## 3. 수익·매각가 시나리오 (러프 모델)

RPM·트래픽을 보수적으로 잡은 추정. 실제는 바이럴 여부에 크게 좌우됨.

| 시나리오 | 월 PV(시즌 평균) | RPM | 월 AdSense 순익 | 매각가(30x 가정) |
|---|---:|---:|---:|---:|
| 비관 | 20,000 | $1 | ~$20 (약 2.6만원) | 사실상 비매각 |
| 기본 | 80,000 | $1.5 | ~$120 (약 16만원) | ~$3,600 (EF 기준 미달) |
| 낙관 | 300,000 | $2 | ~$600 (약 78만원) | ~$18,000 (단일의존 감점, 매각 난이도 높음) |

→ **시사점**: 낙관 시나리오(상당한 지속 바이럴)에서도 매각가는 ~$18k 수준이고 단일 이슈·단일 광고원 의존으로
매각 자체가 어렵다. **AdSense·매각을 "주 목표"로 두는 건 비현실적**. 공익 임팩트 + 옵션 보존이 합리적.

## 4. 트랙별 설계 차이 (확정 시 반영)

| 설계 항목 | 공익+AdSense (주) | 자산화/매각 강화 (부/헤지) |
|---|---|---|
| 분석/추적 | 최소 집계(불편시간·참여수) | **GA4 + Search Console + 이벤트 스키마**(매각 실사 대비) |
| 데이터 소유권 | 자체 DB(Supabase) | 동일 + **export/이관 스크립트**, 스키마 문서화 |
| SEO/확산 | OG·기본 메타 | **구조화데이터·sitemap·콘텐츠 페이지** 강화(검색 유입 다변화) |
| AdSense | 비침습 placeholder 1~2곳 | 동일(과밀 금지 — 공익 신뢰 우선) |
| 운영 문서 | 런북 | **SOP 문서화**(오너 개입 최소화 → 배수↑) |
| 재사용성 | 단일 사이트 | **이슈-범용 템플릿화**(다른 이슈 재배포 = 진짜 자산) |

→ 우측(헤지) 항목 대부분은 **공익 운영에도 이득**이고 추가비용이 작으므로 **기본 채택** 권고.
다만 AdSense 과밀·과도 추적은 공익 신뢰를 해치므로 **절제**한다.

---

## 5. 권고

- **확정 권고: dual-track 유지.** 주 = 공익+비침습 AdSense 운영 / 부 = 저비용 자산화 헤지(SEO·분석·데이터소유·문서화·템플릿화).
- **비권장: "처음부터 매각 목표" 단독 트랙** — 단일 이슈·한국어·스파이크·AdSense 단일의존으로 경제성 미달.
- **옵션 트리거**: 한 시즌이라도 지속 트래픽(예: 월 100k PV+ 비시즌에도 유지)이 확인되면 →
  그때 수익 모델 확장(제휴/후원/뉴스레터)과 매각 검토를 켠다. 그 전엔 공익·신뢰 최우선.
